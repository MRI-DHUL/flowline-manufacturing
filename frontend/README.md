# Frontend

Production React and Tailwind CSS code belongs here.

- Trace all functionality and workflow to `../Flowline_Manufacturing_BRD.md`.
- Do not recreate `../wireframe/` or use it as a screen blueprint.
- Consult the wireframe only for the specific visual element requested by the user at implementation time, and reuse only that element.
- Keep reusable UI components separate from role-specific features.
- Keep business rules, authorization, and database credentials out of this layer.
