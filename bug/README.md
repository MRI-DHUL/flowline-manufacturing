# Bug Evidence

Create one folder per defect only after reproducing it, using a stable ID such as `BUG-001`.

Each defect folder must contain:

- A `README.md` with severity, environment, related BRD requirement, reproduction steps, expected and actual results, root cause, fix, and verification.
- Sanitized pre-fix evidence such as `before.png` or logs.
- Post-fix evidence such as `after.png` and the regression-test result.

Do not store credentials, customer-sensitive data, or unsanitized production logs here.
